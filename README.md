Forza Horizon 5 Hub 🏎️

A fan-made information hub dedicated to Forza Horizon 5.

The project provides a simple and modern interface for exploring cars, races, tuning information, and other game-related resources.
✨ Features

    🚗 Car information

    🏁 Race and event information

    🔧 Tuning guides

    🌐 Responsive design

    🔍 Simple car search

    🎨 Modern dark racing-themed interface

🚀 Getting Started

Clone the repository:

git clone https://github.com/your-username/forza-horizon-5-hub.git

Open the project directory:

cd forza-horizon-5-hub

Then open index.html in your browser.
